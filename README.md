# UK Road Accidents Interactive Power BI Dashboard  

**Live screenshots** → see below  
**Full .pbix file** → download from this repo (Road_Accidents_UK.pbix)  

### What this dashboard shows (ready to present to any client)
- Total casualties 2021 vs 2022: –12 % drop (177 k → 155 k)  
- Breakdown by weather, road type, vehicle type, urban/rural, day/night  
- Hot-spot map of the entire United Kingdom (zoomable)  
- Casualties by hour of day – clear peak hours visible  
- Quarterly & monthly trends + severity split (fatal / serious / slight)  
- All visuals 100 % interactive with slicers and drill-down
